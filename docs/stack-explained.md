# Technology Stack — Why Each Tool Is Here

| Area | Technology | Project role |
|---|---|---|
| Frontend | HTML5 | Semantic, SEO-friendly page structure |
| Styling | CSS3 + Bootstrap 5 | Responsive professional UI |
| Interactivity | JavaScript | CTA tracking and Chart.js dashboard rendering |
| Backend | Python + Django | Routing, forms, ORM, admin, lead management |
| Database | MySQL | Leads, subscribers, campaigns, blog posts, metrics |
| Email | SMTP | Production-capable email configuration via environment variables |
| Email platform | Brevo or Mailchimp | Optional real campaign/list automation integration |
| SEO | Google Search Console | Optional verification/performance monitoring |
| Analytics | Google Analytics 4 | Optional traffic/conversion tracking |
| Keyword research | Google Keyword Planner | External research step; no unverified volume is stored as fact |
| Charts | Chart.js | Marketing dashboard visualization |
| Version control | Git + GitHub | Portfolio proof and deployment source |
| Design | Canva | External creative production workflow |
| Deployment | Render | Production web hosting; MySQL can be run as a Render private service |

## Why no React/Docker/Kubernetes?
The brief is a digital-marketing portfolio, so the stack stays intentionally simple. Django templates + Bootstrap + JavaScript are enough to demonstrate the marketing concepts without hiding them behind a complex frontend architecture.
